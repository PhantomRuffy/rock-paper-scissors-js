# Rock Paper Scissors

A browser-based Rock Paper Scissors game built with vanilla HTML, CSS, and JavaScript.

## Features

- Play rock, paper, or scissors against a randomized computer opponent
- Score tracking across sessions using localStorage
- Visual emoji icons for moves
- Reset score button

## What I learned building this

- DOM manipulation with `document.querySelector`
- JavaScript scope — globals vs locals
- Objects vs arrays for structured data
- localStorage for persistent state
- Clean code practices: DRY, separating JS hooks from CSS classes (`js-` prefix convention)
- Git version control

## How to run

Just open `rock-paper-scissors.html` in a browser. No dependencies, no build step.
